# الدوال - Functions

الدوال هي أدوات قوية تساعدنا على تنظيم الكود وإعادة استخدامه!

## ما هي الدالة؟

الدالة مثل وصفة مطبخة - نكتبها مرة واحدة، ونستخدمها عدة مرات!

### لماذا نستخدم الدوال؟

- ✅ لتوفير الوقت - لا نكتب نفس الكود مراراً
- ✅ لتنظيم البرنامج - كل جزء له وظيفة محددة
- ✅ لتسهيل القراءة - الكود يصبح أكثر وضوحاً

## إنشاء دالة

```python
دالة اسم_الدالة() {
    # الكود هنا
    ارجع قيمة
}
```

### مثال بسيط:

```python
دالة ترحيب() {
    ارجع "مرحباً بالعالم!"
}
```

شرح الكود:
- `دالة` - كلمة مفتاحية لإنشاء دالة
- `ترحيب` - اسم الدالة
- `()` - قوسان لتعريف المدخلات (في هذا المثال لا توجد)
- `{}` - أقواس تحتوي على الكود
- `ارجع` - لإرجاع قيمة من الدالة

## استدعاء دالة

للوصول إلى الدالة، نستخدم `ادع`:

```python
دالة ترحيب() {
    ارجع "مرحباً بالعالم!"
}

# استدعاء الدالة
اكتب(ادع ترحيب())
```

النتيجة:
```
مرحباً بالعالم!
```

## الدوال مع المدخلات (المعاملات)

يمكننا إرسال معلومات للدالة:

```python
دالة تحية(الاسم) {
    ارجع "مرحباً " + الاسم + "!"
}
```

### الاستخدام:

```python
اكتب(ادع تحية("أحمد"))
اكتب(ادع تحية("محمد"))
اكتب(ادع تحية("فاطمة"))
```

النتيجة:
```
مرحباً أحمد!
مرحباً محمد!
مرحباً فاطمة!
```

## دوال مع عدة مدخلات

```python
دالة جمع(رقم1, رقم2) {
    ارجع رقم1 + رقم2
}
```

### الاستخدام:

```python
متغير النتيجة = ادع جمع(10, 5)
اكتب(النتيجة)
```

النتيجة:
```
15
```

## أمثلة عملية

### مثال 1: دالة الضرب

```python
دالة ضرب(أ, ب) {
    ارجع أ * ب
}

اكتب(ادع ضرب(3, 4))
اكتب(ادع ضرب(5, 2))
```

النتيجة:
```
12
10
```

### مثال 2: دالة للترحيب بالشخص

```python
دالة مرحب_بالشخص(الاسم, العمر) {
    ارجع "مرحباً " + الاسم + "، عمرك " + العمر + " سنة"
}

اكتب(ادع مرحب_بالشخص("أحمد", 15))
```

النتيجة:
```
مرحباً أحمد، عمرك 15 سنة
```

### مثال 3: دالة لحساب المساحة

```python
دالة مساحة_المستطيل(الطول, العرض) {
    ارجع الطول * العرض
}

متغير مساحة = ادع مساحة_المستطيل(10, 5)
اكتب("مساحة المستطيل: " + مساحة)
```

النتيجة:
```
مساحة المستطيل: 50
```

## دالة تستدعي دالة أخرى

يمكن للدوال استدعاء دوال أخرى!

```python
دالة ضرب_العدد_بنفسه(عدد) {
    ارجع عدد * عدد
}

دالة ضرب_بالاثنين(عدد) {
    ارجع ادع ضرب_العدد_بنفسه(عدد) * 2
}

اكتب(ادع ضرب_بالاثنين(3))
```

النتيجة:
```
18
```

الشرح:
1. `ضرب_العدد_بنفسه(3)` تُرجع `3 * 3 = 9`
2. `ضرب_بالاثنين` تضرب النتيجة في 2: `9 * 2 = 18`

## تمرين عملي 1

اكتب دالة تقوم بجمع ثلاثة أرقام:

```python
دالة مجموع_ثلاثة(أ, ب, ج) {
    ارجع أ + ب + ج
}

اكتب(ادع مجموع_ثلاثة(10, 20, 30))
```

## تمرين عملي 2

اكتب دالة تأخذ الاسم وتُرجع رسالة ترحيب:

```python
دالة ترحيب_شخصي(الاسم) {
    ارجع "يا أهلاً وسهلاً يا " + الاسم + "!"
}

اكتب(ادع ترحيب_شخصي("خالد"))
```

## تمرين عملي 3

اكتب دالة لحساب محيط الدائرة (المساحة = عدد × عدد × 3.14):

```python
دالة مساحة_دائرة(نصف_القطر) {
    ارجع نصف_القطر * نصف_القطر * 3.14
}

اكتب(ادع مساحة_دائرة(5))
```

## تحدي

حاول كتابة دالة تحول درجة الحرارة من مئوية إلى فهرنهايت!

**المعادلة:** فهرنهايت = مئوية × 1.8 + 32

```python
دالة مئوية_إلى_فهرنهايت(درجة_مئوية) {
    ارجع درجة_مئوية * 1.8 + 32
}

اكتب("25 درجة مئوية = " + ادع مئوية_إلى_فهرنهايت(25))
```

## ملخص

✅ تعلمت كيفية إنشاء الدوال باستخدام `دالة`
✅ عرفت كيفية استدعاء الدوال باستخدام `ادع`
✅ استخدمت المدخلات (المعاملات) في الدوال
✅ تعلمت كيفية إرجاع القيم باستخدام `ارجع`
✅ فهمت كيف يمكن للدوال استدعاء دوال أخرى
✅ استخدمت الدوال في أمثلة عملية!

## نصائح مهمة

💡 **اختر أسماء واضحة للدوال**
   - ✅ `جمع`، `ترحيب`، `حساب_المساحة`
   - ❌ `ف`، `دالة1`، `x`

💡 **وظيفة واحدة لكل دالة**
   - ✅ دالة للجمع، دالة للترحيب
   - ❌ دالة تجمع وترحب وتحسب

💡 **استخدم الدوال لتوفير الوقت**
   - إذا كررت نفس الكود، اجعله دالة!

في الدرس القادم، سنتعلم كيفية اتخاذ القرارات باستخدام الشرطيات!
