# اتخاذ القرارات - الشرطيات

في هذا الدرس، سنتعلم كيف نجعل برنامجنا يتخذ قرارات!

## ما هي الشرطيات؟

الشرطيات تسمح للبرنامج باتخاذ قرارات بناءً على شروط معينة، مثل:
- هل العمر أكبر من 18؟
- هل درجة الطالب ناجحة؟
- هل الطقس مشمس؟

## البنية الأساسية

### جملة if (إذا)

```python
إذا الشرط:
    # الكود هنا
```

### مثال بسيط:

```python
متغير العمر = 15

إذا العمر >= 18:
    اكتب("أنت بالغ")
```

## استخدام else (وإلا)

ماذا إذا لم يتحقق الشرط؟ نستخدم `وإلا`:

```python
متغير العمر = 12

إذا العمر >= 18:
    اكتب("أنت بالغ")
وإلا:
    اكتب("ما زلت طفلاً")
```

النتيجة:
```
ما زلت طفلاً
```

## العوامل المنطقية

### عوامل المقارنة

| العامل | المعنى | مثال |
|--------|---------|------|
| `==` | يساوي | `العمر == 18` |
| `!=` | لا يساوي | `الاسم != "علي"` |
| `>` | أكبر من | `الدرجة > 80` |
| `<` | أصغر من | `العدد < 100` |
| `>=` | أكبر من أو يساوي | `العمر >= 18` |
| `<=` | أصغر من أو يساوي | `الدرجة <= 100` |

### عوامل الاتصال (AND, OR)

```python
متغير العمر = 20
متغير له_رخصة = صحيح

# يجب أن يكون العمر >= 18 ولديه رخصة
إذا العمر >= 18 و له_رخصة:
    اكتب("يمكنك قيادة السيارة! 🚗")
```

```python
متغير الطقس = "مشمس"
متغير الحرارة = 25

# إذا كان الطقس مشمس أو درجة الحرارة مناسبة
إذا الطقس == "مشمس" أو الحرارة >= 20:
    اكتب("وقت مثالي للخروج! ☀️")
```

## أمثلة متقدمة

```python
اكتب("=== آلة التقييم ===")

    اكتب("تقدير: B - جيد جداً 🌟🌟")
وإلا إذا الدرجة >= 70:
    اكتب("تقدير: C - جيد 🌟")
وإلا إذا الدرجة >= 60:
    اكتب("تقدير: D - مقبول 👌")
وإلا:
```

### مثال: التحقق من كلمة المرور

```python
متغير كلمة_المرور = اقرأ("أدخل كلمة المرور: ")

إذا كلمة_المرور == "123456":
    اكتب("✅ كلمة المرور صحيحة")
وإلا:
    اكتب("❌ كلمة المرور خاطئة!")
```

### مثال: آلة حاسبة ذكية

```python
اكتب("=== آلة حاسبة ذكية ===")
متغير الرقم1 = اقرأ("الرقم الأول: ")
متغير الرقم2 = اقرأ("الرقم الثاني: ")
اكتب("اختر العملية (+، -، *، /): ")
متغير العملية = اقرأ()

إذا العملية == "+":
    اكتب("النتيجة: " + (الرقم1 + الرقم2))
وإلا إذا العملية == "-":
    اكتب("النتيجة: " + (الرقم1 - الرقم2))
وإلا إذا العملية == "*":
    اكتب("النتيجة: " + (الرقم1 * الرقم2))
وإلا إذا العملية == "/":
    اكتب("النتيجة: " + (الرقم1 / الرقم2))
وإلا:
    اكتب("❌ عملية غير صالحة!")
```

## تمرينات

### تمرين 1: التحقق من العمر

اكتب برنامجاً يسأل عن العمر ويحدد:
- إذا أقل من 6: "أنت طفل صغير"
- إذا بين 6 و 12: "أنت في المرحلة الابتدائية"
- إذا بين 13 و 18: "أنت في المرحلة الثانوية"
- إذا أكبر من 18: "أنت بالغ"

```python
متغير العمر = اقرأ("كم عمرك؟ ")

إذا العمر < 6:
    اكتب("أنت طفل صغير 👶")
وإلا إذا العمر >= 6 و العمر <= 12:
    اكتب("أنت في المرحلة الابتدائية 📚")
وإلا إذا العمر >= 13 و العمر <= 18:
    اكتب("أنت في المرحلة الثانوية 📖")
وإلا:
    اكتب("أنت بالغ 🎓")
```

### تمرين 2: التحقق من الأرقام

```python
متغير العدد = اقرأ("أدخل عدداً: ")

# التحقق من الإيجابي والسالب
إذا العدد > 0:
    اكتب("العدد إيجابي")
وإلا إذا العدد < 0:
    اكتب("العدد سالب")
وإلا:
    اكتب("العدد صفر")

# التحقق من الزوجي والفردي
إذا العدد % 2 == 0:
    اكتب("العدد زوجي")
وإلا:
    اكتب("العدد فردي")
```

### تمرين 3: نظام تسجيل دخول

```python
متغير الاسم = اقرأ("اسم المستخدم: ")
متغير كلمة_المرور = اقرأ("كلمة المرور: ")

إذا الاسم == "أحمد" و كلمة_المرور == "12345":
    اكتب("✅ تسجيل دخول ناجح!")
    اكتب("مرحباً " + الاسم + "!")
وإلا:
    اكتب("❌ اسم المستخدم أو كلمة المرور خاطئة!")
```

## تحدي

اكتب برنامجاً "لعبة تخمين الرقم"!

**الفكرة:**
1. حدد رقماً سرياً (مثلاً: 42)
2. اطلب من المستخدم تخمين الرقم
3. أخبره إذا الرقم:
   - أكبر من الرقم السري
   - أصغر من الرقم السري
   - صحيح!

```python
اكتب("=== لعبة تخمين الرقم ===")
اكتب("أنا فكرت في رقم بين 1 و 100")
اكتب("حاول تخمينه!")

متغير الرقم_السري = 42
متغير التخمين = اقرأ("ما تخمينك؟ ")

إذا التخمين == الرقم_السري:
    اكتب("🎉🎉🎉 إجابة صحيحة!")
    اكتب("لقد خمنت الرقم الصحيح!")
وإلا إذا التخمين > الرقم_السري:
    اكتب("📉 تخمينك كبير جداً!")
    اكتب("حاول برقم أصغر")
وإلا:
    اكتب("📈 تخمينك صغير جداً!")
    اكتب("حاول برقم أكبر")
```

## نصائح مهمة

💡 **استخدم مسافات بوضوح**
```python
# صحيح ✅
إذا العمر >= 18:
    اكتب("بالغ")

# ❌ سيء (لا تقرأ)
إذا العمر>=18:اكتب("بالغ")
```

```python
# تأكد من اختبار:
# - الشرط صحيح

# - الحالات الخاصة
```

💡 **استخدم متغيرات واضحة**
```python

متغير درجة_الطالب = 85

# ❌ سيء
متغير x = 85
```
