# مرجع سريع - Quick Reference

دليل سريع لجميع الكلمات المفتاحية والعمليات في لغة رمز!

## 📋 الكلمات المفتاحية

### المتغيرات والأنواع

| الكلمة | الاستخدام | مثال |
|--------|----------|------|
| `متغير` | تعريف متغير | `متغير الاسم = "أحمد"` |
| `رقم` | نوع عدد صحيح | `متغير العمر: رقم = 15` |
| `عشري` | نوع عدد عشري | `متغير الطول: عشري = 1.75` |
| `نص` | نوع نص | `متغير الرسالة: نص = "مرحباً"` |
| `منطقية` | نوع منطقي | `متغير نشط: منطقية = صحيح` |
| `قائمة` | نوع قائمة | `متغير ق: قائمة = [1, 2, 3]` |
| `قاموس` | نوع قاموس | `متغير م: قاموس = {ك: ق}` |
| `زوج` | نوع زوج | `متغير ز: زوج = (1, 2)` |

### التحكم

| الكلمة | الاستخدام | مثال |
|--------|----------|------|
| `إذا` | بداية شرط | `إذا العمر >= 18:` |
| `وإلا إذا` | شرط بديل | `وإلا إذا العمر < 18:` |
| `وإلا` | بديل نهائي | `وإلا:` |
| `بينما` | حلقة while | `بينما عداد < 10:` |
| `افعل` | بداية do-while | `افعل:` |
| `طالما` | نهاية do-while | `طالما الشرط` |
| `لكل` | حلقة for | `لكي عنصر في القائمة:` |
| `من` | بداية نطاق | `لكي i من 1 إلى 10:` |
| `إلى` | نهاية نطاق | `من 1 إلى 10` |
| `خطوة` | خطوة النطاق | `من 1 إلى 10 خطوة 2` |
| `في` | في قائمة | `لكي عنصر في القائمة:` |
| `اوقف` | إيقاف حلقة | `اوقف` |
| `تخطي` | تخطي تكرار | `تخطي` |

### الدوال

| الكلمة | الاستخدام | مثال |
|--------|----------|------|
| `دالة` | تعريف دالة | `دالة اسم():` |
| `ارجع` | إرجاع قيمة | `ارجع قيمة` |
| `ادع` | استدعاء دالة | `ادع اسم()` |

### الإدخال والإخراج

| الكلمة | الاستخدام | مثال |
|--------|----------|------|
| `اكتب` | طباعة | `اكتب("مرحباً")` |
| `اقرأ` | قراءة من المستخدم | `اقرأ("اسمك؟ ")` |

## 🔢 العمليات الحسابية

| العملية | الرمز | مثال | النتيجة |
|---------|--------|-------|---------|
| جمع | `+` | `5 + 3` | 8 |
| طرح | `-` | `10 - 4` | 6 |
| ضرب | `*` | `6 * 7` | 42 |
| قسمة | `/` | `20 / 4` | 5 |
| باقي | `%` | `17 % 5` | 2 |

## ⚖️ عمليات المقارنة

| العملية | الرمز | مثال | النتيجة |
|---------|--------|-------|---------|
| يساوي | `==` | `5 == 5` | صحيح |
| لا يساوي | `!=` | `5 != 3` | صحيح |
| أكبر من | `>` | `10 > 5` | صحيح |
| أصغر من | `<` | `3 < 7` | صحيح |
| أكبر من أو يساوي | `>=` | `5 >= 5` | صحيح |
| أصغر من أو يساوي | `<=` | `3 <= 5` | صحيح |

## 🔗 عمليات منطقية

| العملية | الرمز | مثال |
|---------|--------|-------|
| و | `و` | `العمر >= 18 و له_رخصة` |
| أو | `أو` | `الطقس == "مشمس" أو لدي_مظلة` |
| ليس | `ليس` | `ليس متعب` |

## 📦 القوائم

### إنشاء قائمة:

```python
متغير القائمة = [1, 2, 3, 4, 5]
```

### الوصول للعناصر:

```python
القائمة[0]   # أول عنصر
القائمة[-1]  # آخر عنصر
```

### تحديد نطاق:

```python
القائمة[0:3]   # من البداية إلى الموضع 3
القائمة[3:]    # من الموضع 3 للنهاية
القائمة[:5]    # من البداية إلى الموضع 5
```

## 📒 القواميس

### إنشاء قاموس:

```python
متغير القاموس = {"مفتاح": "قيمة"}
```

### الوصول للقيم:

```python
القاموس["مفتاح"]  # "قيمة"
```

## 🔗 زوج (Tuple)

### إنشاء زوج:

```python
متغير الزوج = (1, 2)
```

### الوصول للعناصر:

```python
الزوج[0]  # 1
الزوج[1]  # 2
```

## 📝 البنية الأساسية

### تعريف متغير:

```python
متغير الاسم = "قيمة"
```

### تحديد النوع:

```python
متغير الاسم: نص = "أحمد"
```

### الشرطية:

```python
إذا الشرط:
    # كود هنا
وإلا:
    # كود بديل
```

### حلقة while:

```python
بينما الشرط:
    # كود هنا
```

### حلقة for مع قائمة:

```python
لكي عنصر في القائمة:
    # كود هنا
```

### حلقة for مع نطاق:

```python
لكي متغير من البداية إلى النهاية:
    # كود هنا
```

### دالة بسيطة:

```python
دالة اسم_الدالة() {
    # كود هنا
    ارجع قيمة
}
```

### دالة مع معاملات:

```python
دالة اسم_الدالة(المعامل1, المعامل2) {
    # كود هنا
    ارجع قيمة
}
```

### استدعاء دالة:

```python
ادع اسم_الدالة(قيمة1, قيمة2)
```

## 🎯 أمثلة سريعة

### Hello World:

```python
اكتب("مرحباً بالعالم!")
```

### المتغيرات:

```python
متغير الاسم = "أحمد"
متغير العمر = 15
```

### الشرطيات:

```python
إذا العمر >= 18:
    اكتب("بالغ")
وإلا:
    اكتب("طفل")
```

### الحلقات:

```python
لكي i من 1 إلى 10:
    اكتب(i)
```

### الدوال:

```python
دالة جمع(أ, ب) {
    ارجع أ + ب
}

اكتب(ادع جمع(5, 3))
```

### القوائم:

```python
متغير الأسماء = ["أحمد", "محمد", "خالد"]
لكي اسم في الأسماء:
    اكتب(اسم)
```

## 🔧 نصائح سريعة

### تسمية المتغيرات:
- ✅ استخدم أسماء عربية واضحة: `الاسم`, `العمر`
- ❌ تجنب الأسماء الغامضة: `x`, `y`, `z`

### كتابة الكود:
- ✅ استخدم مسافات بوضوح: `إذا العمر >= 18:`
- ❌ لا تكتب بدون مسافات: `إذا العمر>=18:`

### التعليقات:
- ✅ استخدم `#` للتعليقات: `# هذا تعليق`
- ✅ علّق الكود المعقد لتفسيره

### الأخطاء الشائعة:
- ❌ نسيان `:` بعد الشرط والحلقة
- ❌ نسيان `وإلا` عند الحاجة
- ❌ استخدام `=` بدلاً من `==` في المقارنة
- ❌ نسيان الترقيم من 0 في القوائم
