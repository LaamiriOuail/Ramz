# أول برنامج لك - Hello World

مرحباً بك! في هذا الدرس، سنكتب أول برنامج باستخدام لغة رمز.

## ماذا سنتعلم؟

- كيفية كتابة برنامج بسيط
- كيفية طباعة نص على الشاشة
- أساسيات لغة رمز

## البرنامج الأول

اكتب هذا الكود:

```python
اكتب("مرحبا بالعالم!")
```

ماذا يفعل هذا البرنامج؟

- `اكتب` - هذا دالة تقوم بطباعة النص على الشاشة
- `()` - القوسان يستخدمان لتقديم المدخلات للدالة
- `"مرحبا بالعالم!"` - هذا النص سيتم طباعته
- `""` - العلامتان تشيران إلى أن هذا نص

## جرب بنفسك!

1. افتح سطر الأوامر
2. اكتب `ramz` للدخول إلى بيئة البرمجة
3. اكتب الكود أعلاه
4. اضغط Enter
5. سترى: `مرحبا بالعالم!`

## تمرين

حاول تغيير النص إلى اسمك:

```python
اكتب("اسمي أحمد")
```

مثال آخر:

```python
اكتب("أحب البرمجة!")
```

## ملخص

✅ تعلمت كيفية طباعة النصوص باستخدام `اكتب()`
✅ تعرفت على كيفية كتابة النصوص باستخدام `""`
✅ كتبت أول برنامج لك!

في الدرس القادم، سنتعلم كيفية تخزين المعلومات باستخدام المتغيرات.
