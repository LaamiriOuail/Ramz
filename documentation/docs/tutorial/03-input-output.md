# القراءة والكتابة - Input and Output

في هذا الدرس، سنتعلم كيفية التحدث مع المستخدم!

## كتابة المخرجات - Write

لقد تعرفنا بالفعل على `اكتب()`:

```python
اكتب("مرحبا بالعالم!")
اكتب(100)
اكتب("النتيجة: " + 10)
```

## قراءة المدخلات - Read

الدالة `اقرأ()` تسمح لك بالحصول على مدخلات من المستخدم:

### قراءة بدون رسالة

```python
متغير الاسم = اقرأ()
```

### قراءة مع رسالة

```python
متغير الاسم = اقرأ("ما اسمك؟ ")
```

## برنامج: مرحبا بك!

```python
# سؤال المستخدم عن اسمه
اكتب("مرحبا بك في رمز!")
متغير الاسم = اقرأ("ما اسمك؟ ")

# طلب العمر
متغير العمر = اقرأ("كم عمرك؟ ")

# ترحيب شخصي
اكتب("مرحبا " + الاسم + "!")
اكتب("عمرك " + العمر + " سنة")

# رسالة إضافية
إذا العمر >= 18:
    اكتب("أنت بالغ!")
وإلا:
    اكتب("ما زلت طفلا!")
```

## برنامج: آلة حاسبة بسيطة

```python
# قراءة الرقم الأول
متغير رقم1 = اقرأ("أدخل الرقم الأول: ")

# قراءة الرقم الثاني
متغير رقم2 = اقرأ("أدخل الرقم الثاني: ")

# الحسابات
متغير مجموع = رقم1 + رقم2
متغير فرق = رقم1 - رقم2
متغير حاصل = رقم1 * رقم2

# طباعة النتائج
اكتب("المجموع: " + مجموع)
اكتب("الفرق: " + فرق)
اكتب("الحاصل: " + حاصل)
```

## برنامج: مخزون بسيط

```python
# معلومات المتجر
اكتب("=== متجر العاب ===")

# قراءة عدد الألعاب
متغير عدد_الألعاب = اقرأ("كم لعبة لديك؟ ")

# قراءة السعر لكل لعبة
متغير السعر = اقرأ("ما سعر اللعبة الواحدة؟ ")

# حساب الإجمالي
متغير الإجمالي = عدد_الألعاب * السعر

# طباعة النتيجة
اكتب("عدد الألعاب: " + عدد_الألعاب)
اكتب("سعر اللعبة: " + السعر)
اكتب("الإجمالي: " + الإجمالي)
```

## تلميحات مهمة

### 1. المسافات مهمة
```python
# صحيح ✅
اقرأ("ما اسمك؟ ")

# يمكن بدون مسافة بعد السؤال
اقرأ("ما اسمك؟")
```

### 2. دمج النصوص
```python
# استخدم علامة + لدمج النصوص
اكتب("مرحبا " + الاسم)

# يمكنك دمج أكثر من نص
اكتب("مرحبا " + الاسم + "، عمرك " + العمر)
```

### 3. الأرقام والنصوص
```python
# اقرأ() تقرأ النصوص
متغير العمر = اقرأ("عمرك: ")

# يمكنك استخدامها في العمليات الحسابية
متغير السنة_القادمة = العمر + 1
اكتب("في السنة القادمة سيكون عمرك: " + السنة_القادمة)
```

## تحدي: برنامج التسجيل

اكتب برنامجاً يسأل المستخدم عن:
- الاسم
- العمر
- المدينة
- الهواية

ثم يطبع ملخصاً كاملاً:

```python
اكتب("=== نموذج التسجيل ===")
اكتب("")

متغير الاسم = اقرأ("الاسم: ")
متغير العمر = اقرأ("العمر: ")
متغير المدينة = اقرأ("المدينة: ")
متغير الهواية = اقرأ("الهواية: ")

اكتب("")
اكتب("=== معلوماتك ===")
اكتب("الاسم: " + الاسم)
اكتب("العمر: " + العمر)
اكتب("المدينة: " + المدينة)
اكتب("الهواية: " + الهواية)
اكتب("")
اكتب("شكراً للتسجيل!")
```

## تمرين إضافي

أنشئ برنامجاً يحسب متوسط ثلاث درجات:

```python
# قراءة الدرجات
متغير درجة1 = اقرأ("الدرجة الأولى: ")
متغير درجة2 = اقرأ("الدرجة الثانية: ")
متغير درجة3 = اقرأ("الدرجة الثالثة: ")

# حساب المجموع
متغير المجموع = درجة1 + درجة2 + درجة3

# حساب المتوسط
متغير المتوسط = المجموع / 3

# طباعة النتيجة
اكتب("المجموع: " + المجموع)
اكتب("المتوسط: " + المتوسط)

# تحديد النجاح
إذا المتوسط >= 50:
    اكتب("🎉 ناجح!")
وإلا:
    اكتب("❌ راسب")
```
