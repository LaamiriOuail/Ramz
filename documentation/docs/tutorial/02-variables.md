# المتغيرات - Variables

المتغيرات مثل الصناديق التي نحتفظ بها بالمعلومات داخلها.

## ما هو المتغير؟

المتغير هو مكان نحفظ فيه البيانات لنستخدمها لاحقاً.

## إنشاء متغير

```python
متغير العمر = 10
```

شرح الكود:
- `متغير` - كلمة مفتاحية لإنشاء متغير جديد
- `العمر` - اسم المتغير (يمكن أن يكون أي اسم بالعربية)
- `=` - علامة التساوي (نضع القيمة على يمينها)
- `10` - القيمة المخزنة في المتغير

## أنواع البيانات

### 1. الأرقام (رقم)

```python
متغير العمر = 15
متغير الدرجة = 95
متغير السنوات = 3
```

### 2. النصوص (نص)

```python
متغير الاسم = "أحمد"
متغير المدينة = "القاهرة"
متغير الرسالة = "مرحبا"
```

### 3. الأرقام العشرية (عشري)

```python
متغير الطول = 1.75
متغير الوزن = 65.5
متغير السعر = 99.99
```

### 4. القيم المنطقية (منطقية)

```python
متغير سعيد = صحيح
متغير متعب = خطأ
```

`صحيح` = true | `خطأ` = false

### 5. القوائم (قائمة)

```python
متغير الأرقام = [1, 2, 3, 4, 5]
متغير الأسماء = ["أحمد", "محمد", "خالد"]
```

### 6. القواميس (قاموس)

```python
متغير الطالب = {"الاسم": "محمد", "العمر": 12}
```

### 7. الأزواج (زوج)

```python
متغير الإحداثيات = (10, 20)
```

## تغيير قيمة المتغير

```python
متغير العمر = 10
العمر = 15
اكتب(العمر)
```

## استخدام المتغيرات

```python
متغير الاسم = "أحمد"
متغير العمر = 12
اكتب("اسمي " + الاسم + " وعمري " + العمر)
```

## تسمية المتغيرات

✅ أسماء جيدة:
- `الاسم`
- `العمر`
- `المدينة`
- `النتيجة`

❌ أسماء سيئة:
- `1اسم` (لا يبدأ برقم)
- `اسم طويل جدا` (استخدم أسماء قصيرة)
- `الاسم!` (لا تستخدم علامات خاصة)

## تمرين عملي

```python
# أنشئ متغيرات عنك
متغير اسمي = "اسمك هنا"
متغير عمري = عمرك
متغير مدرستي = "مدرستك هنا"

# اطبع المعلومات
اكتب("اسمي: " + اسمي)
اكتب("عمري: " + عمري)
اكتب("مدرستي: " + مدرستي)
```

## تحدي

حاول إنشاء برنامج يسأل المستخدم عن اسمه ثم يرحب به:

```python
اكتب("ما اسمك؟")
متغير الاسم = اقرأ()
اكتب("مرحبا " + الاسم + "!")
```
