## ما هي لغة رمز؟

رمز هي لغة برمجة عربية مصممة للأطفال! 🌟

### مميزات رمز:

- 🌍 **عربية بالكامل** - جميع الكلمات والمصطلحات عربية
- 👶 **سهلة التعلم** - مبنية بأسلوب بسيط للأطفال
- 🎨 **كلمات مفتاحية عربية** - لا حاجة لإنجليزية
- 🎮 **ممتعة** - برامج تفاعلية وممتعة
- 🔧 **قوية** - تدعم جميع المفاهيم البرمجية الأساسية
- 📝 **رسائل خطأ عربية** - فهم سهل للأخطاء

## التثبيت والبدء

### المتطلبات:

- 💻 جهاز كمبيوتر
- 🦀 Rust 1.70 أو أحدث
- 💡 حاسوب إنترنت (للتحميل)

### التثبيت:

```bash
# استنساخ المشروع
git clone https://github.com/LaamiriOuail/Ramz.git

# الدخول للمجلد
cd Ramz

# البناء
cargo build --release

# التشغيل
./target/release/ramz
```

### أو باستخدام Cargo:

```bash
# التشغيل المباشر
cargo run
```

## أول برنامج لك

### برنامج Hello World

```python
اكتب("مرحباً بالعالم!")
```

**الشرح:**
- `اكتب()` - دالة طباعة على الشاشة
- `"مرحباً بالعالم!"` - النص المطبوع
- `""` - علامات التنصيص للنصوص

### جرب بنفسك:

```python
اكتب("مرحباً")
اكتب("أحب البرمجة!")
اكتب("أنا أتعلم رمز")
```

## المتغيرات

### ما هو المتغير؟

المتغير صندوق نخزن فيه بيانات!

### إنشاء متغير:

```python
متغير الاسم = "أحمد"
متغير العمر = 15
متغير النشط = صحيح
```

### استخدام المتغير:

```python
متغير الاسم = "أحمد"
اكتب("مرحباً " + الاسم + "!")
```

### تغيير قيمة المتغير:

```python
متغير العمر = 15
العمر = 16
اكتب(العمر)  # 16
```

## الأنواع

### الأنواع الأساسية:

```python
# رقم (أعداد صحيحة)
متغير العمر: رقم = 15

# عشري (أعداد عشرية)
متغير الطول: عشري = 1.75

# نص (نصوص)
متغير الاسم: نص = "أحمد"

# منطقية (صحيح/خطأ)
متغير سعيد: منطقية = صحيح
```

### الأنواع المتقدمة:

```python
# قائمة (مجموعة من العناصر)
متغير الأرقام: قائمة = [1, 2, 3, 4, 5]

# قاموس (مفتاح: قيمة)
متغير الطالب: قاموس = {"الاسم": "أحمد", "العمر": 15}

# زوج (زوج من القيم)
متغير الإحداثيات: زوج = (10, 20)
```

## العمليات

### العمليات الحسابية:

```python
متغير أ = 10
متغير ب = 5

اكتب(أ + ب)   # 15 (جمع)
اكتب(أ - ب)   # 5 (طرح)
اكتب(أ * ب)   # 50 (ضرب)
اكتب(أ / ب)   # 2 (قسمة)
اكتب(أ % ب)   # 0 (باقي القسمة)
```

### عمليات المقارنة:

```python
متغير أ = 10
متغير ب = 5

اكتب(أ == ب)  # خطأ (يساوي)
اكتب(أ != b)  # صحيح (لا يساوي)
اكتب(أ > b)   # صحيح (أكبر من)
اكتب(أ < b)   # خطأ (أصغر من)
```

## الشرطيات

### بنية الشرط:

```python
إذا الشرط:
    # الكود هنا
وإلا:
    # الكود البديل
```

### مثال بسيط:

```python
متغير العمر = 15

إذا العمر >= 18:
    اكتب("أنت بالغ")
وإلا:
    اكتب("أنت طفل")
```

### شروط متعددة:

```python
متغير الدرجة = 85

إذا الدرجة >= 90:
    اكتب("ممتاز")
وإلا إذا الدرجة >= 80:
    اكتب("جيد جداً")
وإلا إذا الدرجة >= 70:
    اكتب("جيد")
وإلا:
    اكتب("تحتاج للمحاولة")
```

## الحلقات

### حلقة while (بينما):

```python
متغير عداد = 1

بينما عداد <= 5:
    اكتب(عداد)
    عداد = عداد + 1
```

### حلقة for (لكل):

```python
متغير الأرقام = [1, 2, 3, 4, 5]

لكي رقم في الأرقام:
    اكتب(رقم)
```

### حلقة for مع نطاق:

```python
لكي i من 1 إلى 10:
    اكتب(i)
```

## القوائم والمجموعات

### القوائم:

```python
# إنشاء قائمة
متغير الأسماء = ["أحمد", "محمد", "خالد"]

# الوصول للعناصر
اكتب(الأسماء[0])  # أحمد
اكتب(الأسماء[1])  # محمد

# إضافة عنصر
الأسماء = الأسماء + ["فاطمة"]
```

### القواميس:

```python
# إنشاء قاموس
متغير الطالب = {
    "الاسم": "أحمد",
    "العمر": 15,
    "المدينة": "القاهرة"
}

# الوصول للقيم
اكتب(الطالب["الاسم"])    # أحمد
اكتب(الطالب["العمر"])    # 15
```

## الدوال

### إنشاء دالة:

```python
دالة اسم_الدالة(المعامل1, المعامل2) {
    # الكود هنا
    ارجع قيمة
}
```

### مثال بسيط:

```python
دالة ترحيب() {
    ارجع "مرحباً بالعالم!"
}

اكتب(ادع ترحيب())
```

### دالة مع معاملات:

```python
دالة جمع(أ, ب) {
    ارجع أ + ب
}

اكتب(ادع جمع(10, 5))  # 15
```

## أمثلة عملية

### مثال 1: آلة حاسبة

```python
اكتب("=== آلة حاسبة ===")

متغير ر1 = اقرأ("الرقم الأول: ")
متغير ر2 = اقرأ("الرقم الثاني: ")

اكتب("المجموع: " + (r1 + r2))
اكتب("الفرق: " + (r1 - r2))
اكتب("الحاصل: " + (r1 * r2))
اكتب("القسمة: " + (r1 / r2))
```

### مثال 2: لعبة التخمين

```python
اكتب("=== لعبة التخمين ===")
اكتب("أنا فكرت في رقم بين 1 و 100")

متغير الرقم_السري = 42
متغير خمن_صحيح = خطأ

بينما ليس خمن_صحيح:
    متغير التخمين = اقرأ("تخمينك: ")

    إذا التخمين == الرقم_السري:
        خمن_صحيح = صحيح
        اكتب("🎉 مبروك!")
    وإلا إذا التخمين > الرقم_السري:
        اكتب("📉 كبير جداً!")
    وإلا:
        اكتب("📈 صغير جداً!")
```

### مثال 3: قائمة المهام

```python
اكتب("=== قائمة المهام ===")

متغير المهام = [
    "إنجاز الواجب",
    "مراجعة الدرس",
    "القراءة لمدة ساعة"
]

اكتب("المهام:")
متغير عداد = 1
لكي مهمة في المهام:
    اكتب(عداد + ". " + مهمة)
    عداد = عداد + 1
```

### مثال 4: تحليل الدرجات

```python
اكتب("=== تحليل الدرجات ===")

متغير الدرجات = [85, 92, 78, 88, 95]

# حساب المجموع
متغير المجموع = 0
لكي درجة في الدرجات:
    المجموع = المجموع + درجة

# حساب المتوسط
متغير المتوسط = المجموع / 5

# التقييم
اكتب("المتوسط: " + المتوسط)

إذا المتوسط >= 90:
    اكتب("تقدير: A")
وإلا إذا المتوسط >= 80:
    اكتب("تقدير: B")
وإلا إذا المتوسط >= 70:
    اكتب("تقدير: C")
وإلا:
    اكتب("تقدير: D")
```

## نصائح مهمة

### 💡 تلميحات البرمجة:

1. **ابدأ بسيطاً**
   ```python
   # ✅ ابدأ بالبسيط
   اكتب("مرحباً")

   # ❌ لا تبدأ بالمعقد
   # (كود معقد جداً هنا)
   ```

2. **استخدم أسماء واضحة**
   ```python
   # ✅ جيد
   متغير اسم_الطالب = "أحمد"

   # ❌ سيء
   متغير x = "أحمد"
   ```

3. **اختبر الكود**
   ```python
   # اختبر كل جزء
   اكتب("خطوة 1")
   # كود خطوة 1

   اكتب("خطوة 2")
   # كود خطوة 2
   ```

4. **علّق الكود**
   ```python
   # ✅ أضف تعليقات
   # هذا يحسب المجموع
   المجموع = أ + ب
   ```

5. **تعلم بالخطأ**
   ```python
   # لا تخف من الأخطاء!
   # الأخطاء جزء من التعلم
   اكتب("تعلم من أخطائي")
   ```
