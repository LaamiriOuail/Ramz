## ما هي لغة رمز؟

رمز هي لغة برمجة عربية مصممة للأطفال! 🌟

### مميزات رمز:

- 🌍 **عربية بالكامل** - جميع الكلمات والمصطلحات عربية
- 👶 **سهلة التعلم** - بنية بسيطة تشبه لغة بايثون
- 🎮 **ممتعة** - برامج تفاعلية وأمثلة ممتعة
- 🔧 **قوية** - تدعم جميع المفاهيم البرمجية الأساسية
- 📝 **رسائل خطأ عربية** - فهم الأخطاء بسهولة

## التثبيت والبدء

### المتطلبات:

- 💻 جهاز كمبيوتر
- 🦀 Rust 1.70 أو أحدث
- 💡 اتصال إنترنت (للتحميل)

### التثبيت:

\`\`\`bash
# استنساخ المشروع
git clone https://github.com/LaamiriOuail/Ramz.git

# الدخول للمجلد
cd Ramz

# البناء
cargo build --release

# التشغيل
./target/release/ramz
\`\`\`

### أو باستخدام Cargo:

\`\`\`bash
# التشغيل المباشر
cargo run
\`\`\`

## خريطة التعلم

### المرحلة 1: الأساسيات (1-2 أسابيع)
- ✅ أول برنامج
- ✅ المتغيرات
- ✅ الأنواع
- ✅ العمليات

### المرحلة 2: التحكم (2-3 أسابيع)
- ✅ الشرطيات
- ✅ الحلقات
- ✅ الدوال البسيطة

### المرحلة 3: البيانات (2-3 أسابيع)
- ✅ القوائم
- ✅ القواميس
- ✅ الأزواج

### المرحلة 4: التطبيق (3-4 أسابيع)
- ✅ مشاريع عملية
- ✅ برامج تفاعلية
- ✅ تطبيق المفاهيم

## نصائح مهمة

### 💡 تلميحات البرمجة:

1. **ابدأ ببساطة**
   \`\`\`python
   # ✅ ابدأ بالبسيط
   اكتب("مرحباً")
   
   # ❌ لا تبدأ بالمعقد
   # (كود معقد جداً هنا)
   \`\`\`

2. **استخدم أسماء واضحة**
   \`\`\`python
   # ✅ جيد
   متغير اسم_الطالب = "أحمد"
   
   # ❌ سيء
   متغير x = "أحمد"
   \`\`\`

3. **اختبر الكود**
   \`\`\`python
   # اختبر كل جزء
   اكتب("خطوة 1")
   # كود خطوة 1
   
   اكتب("خطوة 2")
   # كود خطوة 2
   \`\`\`

4. **علّق الكود**
   \`\`\`python
   # ✅ أضف تعليقات
   # هذا يحسب المجموع
   المجموع = أ + ب
   \`\`\`

5. **تعلم بالخطأ**
   \`\`\`python
   # لا تخف من الأخطاء!
   # الأخطاء جزء من التعلم
   اكتب("تعلم من أخطائي")
   \`\`\`
