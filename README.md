![Ramz Logo](https://img.shields.io/badge/Ramz-برمجة--blue)

## 🎯 عن رمز

رمز هي لغة برمجة عربية مصممة خصيصاً لتعليم البرمجة للأطفال بأسلوب سهل وممتع. تتميز اللغة باستخدام مصطلحات عربية بسيطة ونوع هجين للكتابة، مما يجعل تعلم البرمجة تجربة سلسة وممتعة.

## ✨ المميزات

- ✅ **كلمات مفتاحية عربية** - جميع الكلمات الرئيسية باللغة العربية
- ✅ **نوع هجين** - دعم النوع الديناميكي مع إمكانية تحديد النوع (اختياري)
- ✅ **سهلة التعلم** - بنية بسيطة تشبه لغة بايثون
- ✅ **دعم كامل للعربية** - كتابة برامج بالكامل بالعربية
- ✅ **بيئة تفاعلية (REPL)** - تجربة البرمجة مباشرة
- ✅ **رسائل خطأ عربية** - فهم الأخطاء بسهولة
- ✅ **أنواع بيانات متعددة** - رقم، عشري، نص، منطقية، قائمة، قاموس، زوج

## 🚀 التثبيت

### المتطلبات

- Rust 1.70 أو أحدث
- Git

### بناء من المصدر

```bash
git clone https://github.com/LaamiriOuail/Ramz.git
cd Ramz
cargo build --release
```

الملف التنفيذي سيكون في `target/release/ramz`

## 📖 الاستخدام السريع

### وضع التفاعل (REPL)

```bash
cargo run
```

أو بعد التثبيت:

```bash
ramz
```

### تشغيل ملف

```bash
cargo run program.ramz
```

أو:

```bash
ramz program.ramz
```

## 📝 الكلمات المفتاحية

### تعريف المتغيرات
```python
متغير اسم_المتغير = قيمة
```

### أنواع البيانات
- `رقم` - أعداد صحيحة (مثال: 42)
- `عشري` - أعداد عشرية (مثال: 3.14)
- `نص` - نصوص (مثال: "مرحبا")
- `منطقية` - قيم منطقية (صحيح/خطأ)
- `قائمة` - قوائم (مثال: [1, 2, 3])
- `قاموس` - قواميس (مثال: {"مفتاح": "قيمة"})
- `زوج` - أزواج (مثال: (1, 2))

### الإدخال والإخراج
```python
اكتب("مرحبا بالعالم!")
متغير الاسم = اقرأ("ما اسمك؟ ")
```

### الدوال
```python
دالة ترحيب(الاسم) {
    ارجع "مرحباً " + الاسم + "!"
}

اكتب(ادع ترحيب("أحمد"))
```

### العمليات الحسابية
```python
متغير مجموع = 10 + 5
متغير فرق = 20 - 8
متغير حاصل = 6 * 7
متغير قسمة = 100 / 5
```

### التعبيرات المنطقية
```python
إذا العمر >= 18:
    اكتب("أنت بالغ")
وإلا:
    اكتب("أنت طفل")
```

## 🎓 أمثلة

### برنامج الترحيب

```python
اكتب("مرحباً بالعالم!")
```

### حساب بسيط

```python
متغير العمر = 15
متغير السنة_القادمة = العمر + 1
اكتب("في السنة القادمة سيكون عمرك: " + السنة_القادمة)
```

### التعامل مع المستخدم

```python
اكتب("مرحباً بك!")
متغير الاسم = اقرأ("ما اسمك؟ ")
اكتب("مرحباً " + الاسم + "!")
```

### استخدام الدوال

```python
دالة مرحب(الاسم) {
    ارجع "مرحباً " + الاسم + "!"
}

اكتب(ادع مرحب("أحمد"))
```

### استخدام القوائم

```python
متغير الأرقام = [1, 2, 3, 4, 5]
متغير الاسماء = ["أحمد", "محمد", "خالد"]
اكتب(الأرقام)
اكتب(الاسماء)
```

## 📁 هيكل المشروع

```

├── src/
│   ├── ast.rs              # تعريفات شجرة البنية المجردة
```

## 🔨 التطوير

### إضافة ميزة جديدة

1. تعديل الملفات المناسبة في `src/`
2. إضافة اختبارات في `tests/`
3. التأكد من أن جميع الاختبارات تمر:
   ```bash
   cargo test
   ```
4. الالتزام بالتغييرات:
   ```bash
   git add .
   git commit -m "وصف التغيير"
   ```
