# سجل التغييرات - Changelog

All notable changes to the Ramz VSCode extension will be documented in this file.

## [0.1.0] - 2025-02-26 (الإصدار الأولي)

### Added (تمت الإضافة) ✅
- Initial release of Ramz Language Support extension (الإصدار الأولي من دعم لغة رمز)
- Syntax highlighting for all 24 Arabic keywords (تلوين كود لجميع الكلمات العربية الـ24)
- Support for operators, strings, numbers, booleans, and comments (دعم المعاملات والنصوص والأرقام والقيم المنطقية والتعليقات)
- Auto-completion provider with 24 keywords and bilingual descriptions (مزود إكمال تلقائي بـ24 كلمة وأوصاف ثنائية اللغة)
- 15+ code snippets for common programming patterns (15+ مقطع كود للأنماط البرمجة الشائعة)
- Hover documentation with Arabic and English keyword explanations (معلومات عند التمرير بأوصاف عربية وإنجليزية)
- RTL support for proper Arabic text rendering (دعم اليمين-ل-يسار للعرض الصحيح للنص العربي)
- Dual file extensions: `.ramz` and `.رمز` (امتدادات ملفات مزدوجة: `.ramz` و `.رمز`)

### Features (المميزات) 🎯
- Language registration in VSCode (تسجيل اللغة في VSCode)
- TextMate grammar for syntax highlighting (نحو TextMate لتلوين الكود)
- Code completion with context-aware suggestions (إكمال تلقائي باقتراحات ذكية)
- Hover provider for keyword documentation (مزود معلومات عند التمرير للكلمات الرئيسية)
- Language configuration (brackets, comments, indentation) (تكوين اللغة: أقواس، تعليقات، إزاحة)
- Bilingual support (Arabic default, English included) (دعم ثنائي اللغة: عربية افتراضياً، إنجليزية مضمّنة)

### Technical Details (التفاصيل التقنية) 🔧
- TypeScript implementation (تنفيذ بلغة TypeScript)
- Webpack build configuration (تكوين بناء Webpack)
- ESLint configuration (تكوين ESLint)
- VSCode API integration (تكامل مع واجهة برمجة تطبيقات VSCode)
- TextMate JSON grammar format (تنسيق نحو TextMate JSON)

### Documentation (الوثائق) 📚
- README.md in Arabic with English translations (README.md بالعربية مع ترجمات إنجليزية)
- Example Ramz programs (أمثلة برامج رمز)
- Code snippets documentation (توثيق مقاطع الكود)
- Installation instructions (تعليمات التثبيت)
- Usage guide (دليل الاستخدام)

### Known Issues (المشاكل المعروفة) ⚠️
- Custom language icons need to be created (أيقونات اللغة المخصصة تحتاج للإنشاء)
- Error diagnostics not yet implemented (فحص الأخطاء لم يُنفَّذ بعد)
- Code execution not yet implemented (تنفيذ الكود لم يُنفَّذ بعد)
- Debugger support planned for future version (دعم المصرح مُخطَّط لإصدار لاحق)

### Upcoming (قادم) 🚀
